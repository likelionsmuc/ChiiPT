# ChiiPT 🐾

**Interactive Windows Desktop Pet for Posture Awareness & Playful Interaction**

> 귀찮은 알림 대신, 귀여운 캐릭터와 함께 자세도 챙기고 마음도 쉬어갑니다.

**ChiiPT**는 사용자의 자세와 손동작에 반응하는 **Windows 기반 인터랙티브 데스크톱 펫 애플리케이션**입니다.

장시간 PC를 사용하는 동안 무심코 기울어진 자세를 캐릭터의 익살스러운 움직임으로 표현하고, 쓰다듬기와 볼 꼬집기 등의 상호작용을 통해 일상 속 소소한 즐거움과 휴식의 계기를 제공합니다.

기존의 경고나 알림 중심의 자세 관리 방식에서 벗어나, **사용자의 행동에 반응하는 캐릭터를 통해 자발적인 자세 인지와 즐거운 PC 사용 경험을 유도하는 것**이 프로젝트의 핵심 목표입니다.

### 💡 기획 배경

장시간 PC를 사용하는 동안 사용자는 자신의 자세가 기울어지거나 화면에 가까워지는 것을 알아차리지 못할 수 있습니다.

기존의 자세 관리 프로그램이 알림이나 경고를 통해 직접적인 교정을 요구한다면, ChiiPT는 **잘못된 자세에 캐릭터가 대신 반응하는 역발상적인 방식**을 제안합니다.

사용자의 어깨가 기울어지면 캐릭터가 반대 방향으로 달리며 균형을 잡으려 하고, 기울어진 상태가 오래 지속될수록 더욱 힘들어하는 모습을 보여줍니다.

한편 힐링 기능은 학업이나 게임 중 쌓인 스트레스를 키보드를 강하게 두드리는 행동으로 표출하는 주변 사례에서 착안했습니다.

**스트레스를 키보드에 표출하는 대신, 귀여운 캐릭터와 교감하며 잠시 기분을 환기할 수 없을까?**

이러한 생각에서 출발하여 자세 인지와 힐링 상호작용을 하나의 데스크톱 캐릭터에 결합했습니다.

## ✨ Key Features

### 1. Posture Awareness | 자세 불균형 감지

웹캠과 MediaPipe Pose Landmarker를 활용하여 사용자의 어깨 기울기와 화면 접근 변화를 인식합니다.

- **좌우 자세 감지:** 사용자의 어깨가 기울어진 방향을 감지합니다.
- **역방향 달리기:** 캐릭터가 사용자의 기울기와 반대 방향으로 달립니다.
- **단계별 반응:** 기울어진 상태가 지속될수록 달리는 움직임과 몸체 기울기가 커지고, 땀 효과가 추가됩니다.
- **화면 경계 처리:** 화면 끝에 도달하면 이동은 멈추지만 달리는 애니메이션은 유지됩니다.
- **자세 복귀:** 사용자가 자세를 바로잡으면 캐릭터가 화면 중앙으로 돌아옵니다.
- **화면 접근 반응:** 사용자가 카메라에 가까워진 것으로 추정되면 캐릭터가 확대됩니다.

사용자에게 반복적인 경고 문구를 보여주는 대신, **캐릭터의 우스꽝스러운 행동으로 자신의 자세 변화를 자연스럽게 인지하도록 유도**합니다.

### 2. Healing Interaction | 힐링 상호작용

MediaPipe Hand Landmarker를 활용하여 사용자의 손동작을 인식하고, 캐릭터가 다양한 감정 표현과 애니메이션으로 반응합니다.

**🐾 머리 쓰다듬기**

- 캐릭터의 머리 영역에서 손을 좌우로 움직이면 쓰다듬기 동작을 인식합니다.
- 캐릭터가 몸을 비비거나 웃는 듯한 반응을 보여줍니다.
- 하트와 가벼운 움직임을 통해 즐거워하는 모습을 표현합니다.

**🤏 볼 꼬집기**

- 엄지와 검지로 캐릭터의 왼쪽 또는 오른쪽 볼을 꼬집을 수 있습니다.
- 손동작을 유지하면 볼이 당겨진 상태를 표현합니다.
- 손을 놓으면 캐릭터의 볼이 원래 상태로 돌아옵니다.
- 쓰다듬기와 볼 꼬집기 동작이 동시에 실행되지 않도록 제어합니다.

**🐾 마우스 산책**

- 힐링 모드에서 산책 기능을 활성화하면 캐릭터가 마우스 커서를 따라 걷습니다.
- 커서 가까이에 도달하면 멈춥니다.
- 산책을 종료하면 기본 위치로 돌아옵니다.
- 자세 모드 또는 수면 상태에서는 산책 기능이 중단됩니다.

사용자가 작업 중에도 부담 없이 캐릭터와 교감하며 잠시 기분을 환기할 수 있도록 구성했습니다.

### 3. Sleep & Wake | 수면·기상 제어

캐릭터의 수면·기상 상태를 통해 카메라와 인식 기능을 제어합니다.

**🌙 수면**

- 수면 기능 실행 시 카메라와 인식 기능을 중단합니다.
- 캐릭터가 눈을 감고 점차 투명해집니다.
- 잠든 상태에서는 미세한 호흡 움직임을 표현합니다.

**☀️ 기상**

- 기상 기능 실행 시 캐릭터가 기지개를 켜며 깨어납니다.
- 캐릭터의 불투명도가 원래 상태로 복원됩니다.
- 사용자가 선택한 모드의 인식 기능을 재개합니다.

수면·기상은 우클릭 메뉴와 시스템 트레이를 통해 제어할 수 있습니다.

### 4. Stretch Reminder | 스트레칭 알림

장시간 PC 사용 중 잠시 쉬어갈 수 있도록 캐릭터가 직접 스트레칭하는 기능을 제공합니다.

- 기본 알림 간격은 **30분**입니다.
- 사용자가 원하는 알림 간격으로 변경할 수 있습니다.
- 설정한 간격은 로컬에 저장됩니다.
- 알림이 실행되면 캐릭터가 화면 중앙으로 이동합니다.
- 캐릭터가 스트레칭 동작을 반복한 후 원래 위치로 돌아옵니다.
- 수면 상태에서는 스트레칭 알림이 일시중지됩니다.
- 메뉴의 **'지금 스트레칭'** 기능으로 직접 실행할 수도 있습니다.

단순한 알림창 대신 **캐릭터가 직접 스트레칭하는 모습을 통해 휴식의 계기를 제공**합니다.

### 5. Desktop Overlay | 데스크톱 오버레이

Electron 기반의 투명 오버레이를 활용하여 다른 프로그램을 사용하는 동안에도 캐릭터를 화면 위에 표시합니다.

- Windows 작업 표시줄을 고려한 캐릭터 배치
- 다른 프로그램 위에 표시되는 Always-on-top 오버레이
- 캐릭터 외 투명 영역의 마우스 클릭 통과 처리
- 캐릭터 위치와 크기를 고려한 상호작용 영역 처리
- 우클릭 메뉴와 시스템 트레이를 통한 기능 제어
- 자세 모드와 힐링 모드 선택 및 전환
- 웹캠 시작·중단과 장치 선택

자세 인식과 힐링 인식은 동시에 실행하지 않으며, **선택한 모드에 따라 필요한 인식 기능을 활성화**합니다.

## ▶ Getting Started

### 개발 환경

- Windows 데스크톱 환경
- Node.js 및 npm
- 웹캠 또는 호환되는 외장 USB 웹캠

### 설치 및 실행

프로젝트 저장소를 복제합니다.

```powershell
git clone https://github.com/HongJC-PortFolio/ChiiPT.git
cd ChiiPT
```

의존성을 설치합니다.

```powershell
npm ci
```

개발 모드로 실행합니다.

```powershell
npm run dev
```

### 주요 개발 명령어

| 명령어 | 설명 |
|---|---|
| `npm ci` | 고정된 의존성 설치 |
| `npm run dev` | 개발 모드 실행 |
| `npm run typecheck` | TypeScript 타입 검사 |
| `npm run build` | 프로젝트 빌드 |
| `npm test` | 자동 테스트 실행 |
| `npm start` | 빌드된 앱 실행 |

### 기본 사용 방법

1. 앱을 실행하면 Windows 화면 하단에 캐릭터가 표시됩니다.
2. 캐릭터 또는 시스템 트레이의 우클릭 메뉴에서 카메라와 사용할 모드를 선택합니다.
3. 자세 모드에서는 사용자의 어깨 기울기와 화면 접근 변화에 따라 캐릭터가 반응합니다.
4. 힐링 모드에서는 웹캠 앞에서 캐릭터를 쓰다듬거나 볼을 꼬집을 수 있습니다.
5. 필요에 따라 산책, 스트레칭, 수면·기상 기능을 사용할 수 있습니다.

## 🏗 System Architecture

ChiiPT는 **공통 카메라 관리, 독립적인 인식 기능, 통합 캐릭터 제어 및 렌더링 구조**를 중심으로 설계되었습니다.

```text
                    ChiiPT
                      │
              Electron Main
                      │
                   Preload
                      │
               Electron IPC
                      │
                   Renderer
                      │
             ┌────────┴────────┐
             │                 │
       Camera Manager    Character Renderer
             │                 ▲
       ┌─────┴─────┐           │
       │           │           │
  Posture Mode  Healing Mode   │
       │           │           │
  Pose Landmarker Hand Landmarker
       │           │           │
  Posture Logic  Gesture Logic │
       │           │           │
       └─────┬─────┘           │
             │                 │
       Character Controller ───┘
```

### 설계 구조 핵심

**1. 공통 카메라 관리**

자세 모드와 힐링 모드는 공통 카메라 관리 구조를 사용합니다. 모드 전환 시 불필요한 카메라 중복 사용을 줄이고, 수면 상태에서는 카메라와 인식 기능을 중단합니다.

**2. 기능별 독립적인 인식**

자세 인식과 손동작 인식 기능을 분리하여 관리합니다. 각 기능은 인식 결과를 캐릭터 제어에 전달하며, 모드 선택에 따라 활성화됩니다.

**3. 통합 캐릭터 제어**

캐릭터의 이동, 자세 반응, 힐링 동작, 산책, 수면·기상, 스트레칭 상태를 관리하여 서로 다른 애니메이션이 충돌하지 않도록 제어합니다.

**4. Canvas 기반 애니메이션**

캐릭터의 PNG 프레임 이미지를 Canvas 2D로 렌더링합니다. 자세 반응과 캐릭터 이동, 표정 변화 등 기능별 애니메이션을 표현합니다.

**5. 로컬 기반 처리**

웹캠 영상 인식은 사용자 PC에서 수행하며, 카메라 영상을 서버에 전송하거나 저장하지 않습니다. 스트레칭 알림 간격 등 사용자 설정은 로컬 JSON 파일로 관리합니다.

## 🌿 Branch Strategy

| 브랜치 | 용도 |
|---|---|
| `main` | 프로젝트 통합 버전 |
| `feature/posture` | 자세 인식 및 캐릭터 반응 개발 |
| `feature/healing` | 힐링 상호작용 개발 |

- 기능별 개발은 독립 브랜치에서 진행합니다.
- 기능 통합 시 Pull Request를 활용합니다.
- 통합 과정에서 공통 모듈과 애니메이션 동작을 확인합니다.
※ 해커톤 제출용 저장소는 `main` 브랜치로 통합하였으며, 실제 개발 과정에서는 개인 GitHub 저장소에서 `feature/posture`, `feature/healing` 브랜치를 분리하여 기능별 개발 및 버전 관리를 진행했습니다.
